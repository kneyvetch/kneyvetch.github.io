如何计算与解读

思维量表 0–4：未构思出解法、较多提示、少量提示、独立构思、独立构思并证明。代码量表 1–4：未完成实现、协助后 AC、独立编码未 AC、独立编码并 AC。均值是自评量表的描述统计，不能换算为 CF Rating，也不能比较两种量表的高低。

每项取按训练日期排序的最近 30 条有效自评。重复记录 ID 或相同 CF 题号只取第一条；未评估不当作 0 分。标签强弱按每个指标分别至少 3 题判断：均值 ≥3.2 为较强，≤2.4 为待强化。样本门槛不是统计置信度；题目难度和选择偏差仍会影响结果。

常见中英文标签按别名合并；原始记录不会被自动改写。未练习或未标注的知识点只能视为证据不足，不能推断为不会。
