# 训练证据与知识缺口改进

用户已授权选择、实施、测试和发布。本次在现有原生 JS 页面内实现，不改变个人 CF 估值，不重写历史数据。

1. 先增加回归测试：双指标重复计数、标签别名、同题重复、训练日期排序、两期样本门槛、无效日期、缺口重新出现、旧数据兼容。
2. assessment.js 提供只读派生分析：每维度独立样本数；常见标签别名；近 30 条自评；最近和之前各 28 天比较（各至少 5 条），8 个七日区间；未知不当作零。
3. 成长页增加覆盖率、评分尺度、日期与难度说明、趋势和缺口复习。记录页增加标签与评估显示、筛选、精确证据跳转。缺口状态写入对应记录的可选 resolvedGaps，保留原 gaps。
4. 同步仍不生成自评、不覆盖用户注释；补充同步合并回归测试。保持 localStorage 键和 version:1，导入导出透传可选字段。
5. 增加存储失败回滚保护于新增复习操作；更新 service worker 缓存。运行旧测试、新测试和浏览器验证；通过原 Hexo 工作流的加密页面检查后确认 Pages 发布。

取舍：本次不增加模型预测 CF 分数或 AI 推荐，避免将自评和不同难度题的均值伪装成客观能力。趋势明示为记录表现，不声称统计置信度。没有标签不等于知识盲区。
